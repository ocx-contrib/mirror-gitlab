# GitLab CLI

`glab` is the official open-source GitLab CLI tool. It brings GitLab to your
terminal — manage merge requests, issues, CI/CD pipelines, releases, and
repositories without leaving the command line. It works against gitlab.com
and self-managed GitLab instances alike.

## What's included

- **glab** — the GitLab command-line client
